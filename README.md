# App Hotel

Projeto da Agenda 13 de Programação Mobile I, desenvolvido em .NET MAUI, explorando `BindingContext`, `Stepper`, `DatePicker` e `Picker`.

## Telas

- **Cálculo da Diária** (`ContratacaoHospedagem`) — escolha de quantidade de adultos/crianças, tipo de suíte e período de estadia
- **Hospedagem Contratada** (`HospedagemContratada`) — resumo da reserva com o valor total calculado
- **Sobre** (`Sobre`) — tela nova, com informações do desenvolvedor e ano de desenvolvimento

## Personalizações feitas

- Paleta de cores alterada para tons de verde-petróleo (`Resources/Styles/Colors.xaml`)
- Nova tela **Sobre**, acessada pelo botão "Sobre" na tela inicial
- Título do app alterado para "App Hotel - Luiz"

## Como rodar

1. Abra a pasta `MauiAppHotel` no Visual Studio (com a carga de trabalho .NET MAUI instalada)
2. Selecione o emulador/dispositivo de destino (Windows ou Android)
3. Execute o projeto (F5)
